LG 유플러스 Adobe Target / Adobe Campaign 구축

LG 유플러스 / 아이뱅크· 2026.05 — 진행중· 8명 (Target 영역 단독 · Cursor AI)· 구축 PL · 요구사항~고객사 연동 진행중

LG U+ Web/App 개인화 마케팅(Adobe Target) 구축에서 요구사항 정의, 시스템 구조 설계, 커스텀 엔진 개발, 고객사 연동까지 Target 영역을 단독 주도하며 구축 PL을 병행합니다. 제품 기본 기능(OOTB)만으로는 맞추기 어려운 요구는 커스텀 설계로 해결하고, 화면·조건별로 결과가 달라지는 개인화 특성에 맞춰 경로 단위 검증으로 배포 품질을 관리합니다.

Adobe Campaign 영역은 자연어→SQL 타겟 추출 PoC(납품 제외)와 발송 제어(Typology) 정책 설정을 부가 수행합니다.

역할 한줄 요약

고객 TF와 직접 요구사항·고도화 방향을 논의하고, 제안한 로직의 대부분이 실제 설계에 반영되도록 주도. WBS·공수 산정·체크리스트·개발 가이드까지 포함해 구축 전 과정의 기술 리드를 수행합니다.

Target · 설계·구현
  • 요구사항·구조 설계 — TF와 요구사항·고도화 방향 논의, OOTB로 불가한 항목은 커스텀 설계로 전환
  • 클라이언트 엔진 — Target 라이브러리 삽입 방식 기반, 화면 행동 트리거 · Offer(노출 방식) 분기 · dataLayer(행동 데이터 수집 규격) · 이벤트 호출·파라미터 규격 설계·구현
  • 재사용 구조 — 캠페인마다 반복 개발하지 않도록 공통 컴포넌트화(팝업·배너 등)
Target · 데이터·검증
  • 데이터 파이프라인 — 개인화 운영용 수집·적재 흐름, 연관 커스텀 테이블 설계, Campaign 연계 구간 정합성 확보
  • 경로 기반 QA — 조건 분기를 경로 단위로 펼쳐 케이스를 최대한 도출·검증(단일 기능 테스트가 아닌 시나리오 경로 기준)
  • 배포 통제 — 검증 결과를 체크리스트로 관리, 미검증 경로가 배포되지 않도록 통제
협업 · 기술 확보
  • 고객사 Web/App 개발자와 연동 규격 협의 및 구현 조율
  • Adobe(솔루션사)와 제품 제약·권장 구현 방식 확인
  • 공식 문서 기반으로 제품 내부 동작을 이해하고 설계 판단에 반영
Campaign · 부가
  • SQL 생성 PoC — 자연어로 타겟 추출 SQL을 만드는 LLM 파이프라인을 1인 설계·구현(프롬프트·응답 검증·토큰 효율). LG U+ 납품 범위에는 포함되지 않으나, 동일 Adobe Campaign 환경의 다른 고객사에도 적용 가능한 수준으로 검증
  • 발송 제어 — OOTB Typology(유형 규칙) 기반 발송 제어 정책 설정 및 요구사항 반영
